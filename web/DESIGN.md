# LoreLab 配置台界面规范

## 范围与结构

这是后台配置与运行管理界面。四分类固定为连接与服务、采集与费用、存储与导出、任务与诊断；不提供阅读器、文章编辑器或历史风格切换。

桌面结构为“侧栏 → 分组标题 → 具体内容”。品牌与主题切换在侧栏顶部，四分类紧随其后，底部标注示例配置。侧栏贯通窗口，支持短窗口内独立滚动；正文直接从页面标题开始，页内视图紧邻标题。

侧栏宽212px，导航项高44px，项间距4px；品牌区与导航间距24px。桌面分组标题列176px，内容列弹性填充，列间距36px。中间尺寸缩小标题列，内容不足时转单列；760px以下品牌行与四分类横向呈现。内容组、列表、编辑区和保存区不使用横向分隔线，用对齐与留白表达关系。

## 主题与控件

以 [Obsidian 官方 CSS 变量规范](https://docs.obsidian.md/Reference/CSS%20variables/Foundations/Colors) 为基础，参考 [官网](https://obsidian.md/) 的中性黑紫配色。只采用公开变量规范和颜色数值，保留 LoreLab 自有品牌与图标，界面独立实现。

- 深色：背景 `#1c1c1c`，侧栏 `#232323`，编辑区 `#282828`，正文 `#dadada`。
- 浅色：背景 `#ffffff`，侧栏 `#fafafa`，编辑区 `#f6f6f6`，正文 `#222222`。
- 主按钮 `#7c3aed`，悬停 `#6d28d9`；强调文字在深色使用 `#b69df8`，浅色使用 `#6d28d9`。
- 系统无衬线用于界面和品牌，等宽用于路径、时间和日志。界面操作图标统一使用 Lucide；品牌使用自有 SVG。
- 使用4px间距尺度与4/8/12/16px圆角；输入框和主要点击目标至少44px高。

变量在 `obsidian-tokens.css`，现有组件通过语义别名读取；错误、警告、成功文字和表单边界按可读性适配。主题切换保留页面、草稿和流光暂停状态，只在当前会话保留。

品牌采用 A1「错榫」：两枚错开的 L、等宽笔画和连续阶梯留白，两个末端使用一致的45°切角。小尺寸精修收短切角，保持末端厚度；不添加底板、描边或光效。`src/lorelab-mark.svg` 是唯一轮廓源，侧栏以24px蒙版继承当前主题强调色，favicon 随浏览器的深浅色偏好调整紫色。两处资源均在构建时内嵌，独立 HTML 预览无需外部图标文件。

## 配置与诊断

配置使用分组标题和字段内容两列。服务是否启用、连接测试结果、配置是否保存是独立状态。修改后可查看差异、撤销或保存；离开分类前通过弹层处理未保存修改，关闭弹层后返回触发控件。

诊断复用配置分组：服务状态、最近任务、诊断日志纵向排列。服务和任务详情在对应行下按需展开，错误与恢复操作保持可见，日志可组合筛选；手机详情独占内容组宽度。

所有端点、凭据、路径、费用、任务和日志均为合成示例。模拟成功不表示真实服务已连接；UI字段不能直接作为后端契约。

## 流光与响应式

流光沿用已确认的连接关系：直线主干、柔和曲线分支、紫色光点。SVG / Canvas / HTML节点共用 `flow-geometry.ts`。只有已启用且就绪的路径流动；暂停、减少动效、离屏和页面隐藏时停止，切页清理监听与动画帧。

交互优先保证可辨认的选中态、键盘焦点、弹层回焦和手机点击面积。缩放或窄屏以结构重排适配，不压缩内容字号来塞入桌面布局。
